# 《县太爷今天也很忙》设计

> 取代《一夜剧本》。轻松讽刺古风，无死亡、无末日感。

## 核心循环

- 玩家是穷县新任县令。屏幕中央一张人物卡牌 + 上方请求文本。
- 左右拖动卡牌做决定；拖动时卡面显示该方向选项，顶部四项数值上方出现圆点（大小 = 影响幅度，不显示正负）。
- 四项数值 0–100，初始 50：民心 `people`、钱粮 `money`、官声 `court`、良心 `heart`。
- 任一项 ≤0 或 ≥100 即下台（8 种数值结局）。剧情线可直接触发特殊结局。在任满 365 天光荣致仕。
- 每张卡推进 1–3 天；分数 = 在任天数。每 30 天出现知府「年终考核」卡。
- 每局从「第 N 任县令」开始，开场卡引用上一任结局的交接词。

## 内容（第一版）

- 约 12 个角色，头像为朱红印章（单字），无美术素材。
- 约 80 张卡：通用卡、数值条件卡（某项过高/过低时出现，制造救场或推一把）、剧情链卡（`chainOnly`，由选择排入队列）。
- 剧情线：科举舞弊（→告御状）、狐仙（→随狐仙去）、水患（→河伯）、师爷账房、说媒等。
- 结局 12 个：8 数值 + 科举 + 狐仙 + 水患 + 任满。

## 重玩

- 存档（`wx.setStorageSync`）：历任数、最长在任、已解锁结局、见过的角色、上一任结局。
- 卡牌可按 `runs`（历任数）/ `endings`（已解锁结局数）门槛解锁，后续局出现新角色与剧情线。
- 结局图鉴 + 人物图鉴；微信分享带结局文案。

## 数据模型

```js
card = {
  id, who, text,               // text 支持 {n}（第几任）{handoff}（交接词）
  left:  { label, fx: { people, money, court, heart }, flags, chain: { id, delay }, ending },
  right: { ... },
  chainOnly, once, review,
  requires: { flags, notFlags, minDay, stat: { key: [min, max] }, runs, endings },
}
```

## 架构

- `js/core/`：画布与 DPR、触摸手势、补间、WebAudio 程序化音效、存档。
- `js/game/`：纯逻辑（`stats` / `run` / `meta`），无 `wx` 依赖，Node 测试覆盖。
- `js/data/`：角色、卡牌、结局。
- `js/ui/`：纸纹、印章、文字排版缓存。
- `js/scenes/`：标题、游戏、结局、档案；场景间墨迹转场。

## 视觉与手感

宣纸底、浓墨、朱红印章、宋体。高清屏适配；离屏预渲染背景；打字机文本（点击跳过）；卡牌拖拽倾斜、回弹、甩出、翻面入场；数值变化跳动着色；结局印章落下；震动反馈。音效全部程序化合成：惊堂木、纸张、木鱼、古筝拨弦、锣。

## 验证

- `node --test`：数值钳制、抽牌条件 / 队列 / 冷却、结局判定、存档统计、数据完整性（引用有效、链卡可达）、1000 局随机模拟必定终止且结局分布多样。
- 画面需在微信开发者工具中人工确认。
