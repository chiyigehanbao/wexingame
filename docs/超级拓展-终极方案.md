## 0. 一句话定调

**把「一局官场」做成「一任成史」：玩家每一局的选择会塑出一条路数，路数改写后面能遇到的人、事、收场；历任叠上去，世界变厚，重开是好奇，不是换皮刷分。**

文字游戏的可玩性，不靠再堆一百张互不相关的案情卡。靠的是：

1. **中盘必须分叉**（玩到一半，路已经不一样了）
2. **选择会改牌面**（贪、不管事、屯兵、清正，后面抽到的牌池不同）
3. **人会缠着你**（人物有弧，不是一次性道具）
4. **上一任会留下痕迹**（重玩有回声）
5. **每条生活方式都能玩到中途，再各自平衡收场**

下面整份文档只服务这一条定调。不并列三个半吊子方向。

## 1. 现状：雏形已经站住了什么

### 1.1 已经有的骨架（必须保住）

| 层 | 现状 | 评价 |
|---|---|---|
| 核心操作 | 左右滑、选项二字常显、四项 0–100 | 手感正确，别动 |
| 官级 | 县令→…→皇帝，多项称帝 | 高度够，宽度刚开 |
| 系统新闻 | 朝报改国势，无选择 | 正确，继续做「推主线」 |
| 生活方式苗头 | 贪、跳级、青楼、不管事、叛国、调县 | 有种子，还没成体系 |
| 重玩壳 | 三存档、成就一条、档案、历任 | 壳在，内容回声弱 |
| 变现 | 纯广告（烧香祝福），无内购 | 定死，方案里不引入充值 |

### 1.2 真正不够的地方（诊断，不是抱怨）

1. **路数是事件，不是气质。**  
   贪、跳级、青楼、叛国目前多是「once 链 → 结局」。玩家体感是「触发了一次支线」，不是「我这一任在变成另一种官」。玩过两三局，路数感消失。

2. **中盘同质。**  
   前 30 天新鲜，中段容易回到税、修桥、圣旨、剿匪的轮换。称帝线很炫，但多数局到不了；多数局的中段仍缺「我已经回不去了」的分叉感。

3. **人物是印章，不是关系。**  
   12 个角色会反复出场，但缺少「我帮过王婆三次，她后来替我挡了一刀」这种跨卡记忆。文字游戏最贵的乐趣——熟人压力——还没吃满。

4. **县域没有面孔。**  
   永远是「一个穷县」。边县、盐县、水患县、科举县的案情应该不同；现在主要靠官级和国势切换，县本身几乎不变。

5. **重玩的好奇不够。**  
   解锁多靠 runs / endings 门槛，但上一任留下的桥、匾、仇人、私生传闻，很少在下一任真的出现。档案好看，局里回声薄。

6. **结局密度偏「尖」。**  
   皇帝三结局很亮；四项见底很明确；中段生活方式结局刚补了病榻/调任/开城/混过。还缺一批「玩到一半也很体面」的收场，以及「同一路数不同收场」的变奏。

**结论：不要再做一个「再加 50 张日常卡」的方案。要做一个让路数、人物、县域、历任回声咬合的总系统。日常卡是肉，系统是骨。**

## 2. 终极命题：一任成史

### 2.1 玩家每一局在回答什么

不是「四项稳住升官吗」，而是：

> **这一任，你要做哪一种官？最后史册怎么写你？**

四项数值仍是生命线（见底下台）。  
升官仍是主轴之一。  
但主轴旁边，永远有一条**路数轴**：清正 / 贪墨 / 乐逸 / 武备 / 权谋。

### 2.2 为什么这是文字游戏的「一次到底」答案

- 滑卡游戏内容会枯竭；**路数改牌池**让同样 200 张卡变成「这一局只看到其中 60 张，且组合不同」。
- 玩家记得的是故事，不是数值；**人物弧 + 县域气质**把数值选择翻译成可复述的情节。
- 微信小游戏会话短、重开频繁；**历任回声**让第 5 局比第 1 局「世界更熟」，留存靠好奇。
- 广告变现要靠「再来一任」；**每条路都能玩到中途并体面收场**，才有理由再开，而不是开局 20 天暴毙劝退。

### 2.3 明确不走的路（边界）

- 不做开放世界、不做地图点选、不做战斗数值 RPG。  
- 不做内购、月卡、打断式体力。  
- 不做沉重死亡猎奇；病死、兵败、开城都保持现有轻松讽刺语气。  
- 不做「第五项见底就死」的隐藏血条；路数是塑形，不是新的失败条件。  
- 不做引擎说明书式的规矩页；玩法说明永远讲玩家会遇到什么。

## 3. 五大支柱（同一栋楼的五根柱）

```
                 ┌──────── 史册回声（跨局）────────┐
                 │                                 │
    路数塑牌面 ──┼── 人物弧 ── 县域气质 ── 舞台分层 ┤
                 │                                 │
                 └──────── 一局收场（结局经济）─────┘
```

五根柱必须一起立。只加卡、不立柱，三个月后又会「玩几局就不想玩」。

## 4. 支柱一：路数塑牌面（核心系统）

### 4.1 五个路数计数（对玩家可感知，对 UI 可克制）

局内增加五个非失败计数（0 起，软上限约 8～12）：

| 路数 | 典型选择 | 玩家体感 |
|---|---|---|
| 清正 `clean` | 拒贿、办学、平反、赈济 | 越清，清官线与民愿线越多 |
| 贪墨 `graft` | 睁眼、分赃、跳级礼、独吞 | 越贪，油水与翻账线越多 |
| 乐逸 `pleasure` | 青楼、装病、压状纸、听曲 | 越逸，享乐与病榻线越多 |
| 武备 `arms` | 募兵、剿匪、留下兵、起兵 | 越高，兵与边事线越多 |
| 权谋 `scheme` | 改朝跟上、策反、开城、塞银升官 | 越高，夜访与朝堂线越多 |

**规则：**

- 绝大多数选项只给 **+1 某一路数**（偶发 +2）。  
- 路数 **绝不** 在 0 时结束游戏。  
- 路数高了，**改权重 / 解锁 once 包 / 打开中盘岔路**，并轻微拉扯四项（例如贪墨高时 money 来得容易、people/heart 更脆）。  
- UI：不新增第五条大血条。用朝廷页或档案里一行「这一任的气味」展示最高的两项即可（如「贪墨 · 权谋」）。玩法说明写「你常做的事，会引来同一类人」，不写计数公式。

### 4.2 路数如何改抽牌（可玩性的发动机）

抽牌在现有顺序上增加一层 **池过滤**：

1. 每张卡可标 `paths: ['graft']` 或 `paths: ['clean','scheme']`。  
2. 玩家某路数 ≥3：该路专属 once 包进入候选。  
3. 玩家某路数 ≥6：中盘「定性大事件」武装（见 4.3）。  
4. 玩家某路数 ≥8：对应收场链可出现（病榻、调任前夜、清名满天下的钦差夜访等）。  
5. 互斥软规则：清正≥6 时，极贪独吞链权重下降；贪墨≥6 时，办学赈济类权重下降——**下降，不是消失**，避免锁死。

这样：同样「第 80 天」，清官局和贪官局的牌面已经不是同一副。

### 4.3 中盘定性大事件（保证「玩到一半」）

每条路数在大约 **第 60～180 天** 必须有一次「回不去了」的岔路（once，可拒，拒了路数不涨或微降）：

| 路数 | 定性事件名（示例） | 左 | 右 | 后续 |
|---|---|---|---|---|
| 清正 | 名帖满城 | 接着做清官 | 收一点人情 | 清→钦差密访 / 右→路数回落 |
| 贪墨 | 账本到了府里 | 再买一次 | 认了调任 | 续贪或 `transfer` |
| 乐逸 | 郎中第三次上门 | 最后一晚 | 停下来 | `illness` 或转回政务 |
| 武备 | 兵已经听你的 | 握紧 | 裁一半 | 策反/起兵或安稳 |
| 权谋 | 两边都来信 | 跟夜访 | 跟邻国 | `founded` / `traitor` / 两边都拒 |

**硬性验收：** 随机 100 局里，至少 55 局在 day≥90 前触发过至少一次定性事件；五条路各至少 8 局走到对应中段链。

### 4.4 路数与现有称帝线的咬合

- 称帝五路（顺升 / 驾崩进京 / 举旗 / 策反 / 刚升起兵）保留，仍 **一局只称一次**。  
- 路数是「土壤」：武备高更容易抽到举旗/策反；清正+民心高更容易接到驾崩进京；权谋高更容易夜访与邻国。  
- 跳级礼继续存在，记入贪墨+权谋；跳到尚书封顶，皇帝仍走称帝手续。

## 5. 支柱二：人物弧（熟人压力）

### 5.1 每个常驻角色一条 4 拍弧

现有 12 人全部升级为「可记住你」的弧，结构统一：

1. **初见**（已有日常卡）  
2. **交情**（once：帮过 / 驳过）  
3. **考验**（once：把刀架在交情上）  
4. **收束**（once：报答、反噬、离开、或留下信物 flag）

示例（写法标准，不是要现在全写完）：

- **王婆**：三次说媒 → 替你压下绯闻 → 她自己涉案 → 你保或交。  
- **钱满仓**：油水 → 分赃 → 翻账 → 他抬你或咬你。  
- **白小舟**：盘缠 → 办学 → 中举回来 → 写你的德政或参你。  
- **孙不二**：账房 → 替你瞒 → 他自己贪污暴露 → 你割席或同沉。  
- **狐仙**：烧鸡 → 托梦 → 请你走 → 现有 `fox_away` 升级为弧的终点之一。

### 5.2 关系值怎么存

- 局内：`run.bonds[who] = -2..3`（整数）。  
- 跨局：meta 里只存「此人最高交情曾达 X / 曾见过弧终点」，用于解锁下一任更早出现的熟人卡。  
- 选择写 `bond: { who: 'wangpo', d: 1 }`。  
- 抽牌 `requires: { bond: { wangpo: [2, 3] } }`。

### 5.3 为什么这能抬可玩性

文字游戏里，玩家记住的是「我对不起谁」。  
四项是仪表盘；**人物弧是愧疚与人情**。有了它，同样的「左边加民心」会变成「这次是为了王婆」。

**体量目标：** 12 人 × 4 拍 ≈ 48 张弧卡（大量 once）+ 每人 2～3 张日常变奏。

## 6. 支柱三：县域气质（同一套操作，不同县的脸）

### 6.1 开局抽「县面」，局中会变

开局（或第一任固定穷县，后续任可随机）给县贴 1～2 个气质标签：

| 标签 | 案情偏重 | 朝报/边事 |
|---|---|---|
| 穷县 | 赈济、逃户、卖子 | 流民 |
| 边县 | 走私、界河、开城 | 边警高 |
| 盐县 | 私盐、钞引、盐商 | 盐政圣旨 |
| 水县 | 河工、决口、河伯 | 汛期 |
| 学县 | 科举、书院、舞弊 | 开科/停科 |
| 乱县 | 山匪、兵痞、夜访 | 国势低 |

局中重大选择与朝报可 **加标签 / 换标签**（例如连年剿匪失败 → 乱县；办学成功 → 学县）。

### 6.2 标签只改池，不改操作

- 玩家永远左右滑。  
- 标签 = 卡包开关 + 朝报权重。  
- 叛国线优先出现在边县；青楼病榻在富起来的县权重更高；清官办学在学县更容易封神。

### 6.3 与「调到别的县」的关系

现有 `transfer` 结局升级为两种收场：

1. **终局调任**：这一任结束，档案盖「调任」。  
2. **局内改任（推荐做进终极形态）**：官降回县令、**换一个县面标签**、日数与年龄继续、路数保留一半——真正实现「还是县令，但还能再爬」。  
   - 一局最多局内改任一次，防无限拖。  
   - 改任时清空本县 once 工程卡的「已建」记忆中与县绑定的部分（桥、学、仓），保留人物 bond。

## 7. 支柱四：舞台分层（爬上去内容不空）

把内容按舞台切三层，**每层有自己的 once 池**，避免「升到巡抚还在修村口桥」。

### 7.1 县治层（县令～知府）

- 人物弧主场、县域案情、工程 once、青楼/贪墨日常。  
- 目标：任意路数都能在这层玩到 day 120～200。

### 7.2 一路层（按察～尚书）

- 邻府争水、漕运、钦差大案、兵额、节度使式的压力（用现有兵与圣旨扩展）。  
- 知府以上，村口级日常权重下降；一路 once 权重上升。  
- 跳级礼、翻账、调任主要在这层发威。

### 7.3 皇权层（称帝后）

- 保持短链：打仗 / 死守 / 坐朝一年。  
- 可再加 2～3 条「登基后政务链」（宗室、年号、开恩科），但 **不加第二套皇帝养成**。称帝是高光，是收束，是一种史，不是新游戏。

### 7.4 抽牌优先级（定稿口径）

保持现有精神，只加一句：

> 队列剧情 > 定性大事件 > 考核 > 年龄交印 > 称帝相关 > 兵/圣旨 > 人物弧续集 > 县域日常。

故事永不被考核吃掉；考核永不被日常冲掉。

## 8. 支柱五：史册回声（跨局变厚）

### 8.1 三层记忆

| 层 | 存什么 | 下一任怎么用 |
|---|---|---|
| 朝代 | 国号、崩过几次、是否新朝 | 开场师爷一句；朝报池微调 |
| 县域 | 上一任留下的工程/烂摊子 flag | 「前任修的桥又塌了」「前任办的学还在」 |
| 人物 | 弧终点、恩怨 | 熟人更早出现；或换成「故人之后」 |

### 8.2 「第 N 任」的正确用法

- 对白里继续不报任数（保持「新来的县令」）。  
- 史册与档案里报任数。  
- 局里用 **事迹** 回声：「墙上还有块匾，写着清正——是上一任留下的。」

### 8.3 成就与卡包

- 一任仍只落一条成就（保持）。  
- 成就解锁的是 **卡包/人物弧/县面**，不是数值加成。  
- 目标成就约 24～30 条，覆盖五路数、五称帝、边县开城、调任再爬、清名满天下等。

### 8.4 分享与再来一任

每条新结局 `share` 仍以「我」开头，一句就能发出去。  
结局页主按钮永远是「再来一任」心智；烧香祝福保留为广告点。

## 9. 结局经济（每条路都能体面收场）

### 9.1 结局分层

| 层 | 数量目标 | 例子 |
|---|---|---|
| 数值见底 | 4 | 现有民心/钱粮/官声/良心 |
| 生活方式中段 | 12～16 | 病榻、调任、开城、混过、清名迫仕、账破、兵散、名士出走… |
| 高光史诗 | 8～10 | 功成/兵败/坐朝 + 举旗败/进京让位/新朝降级… |
| 奇遇 | 6～8 | 狐仙、河伯、御状、科举等 |
| 任满/交印 | 4 | 任满、致仕、传子、交师爷 |

**合计约 40 个结局。** 不追求 100；追求「每条路至少 2 个不同收场」。

### 9.2 平衡口径（写进验收）

- 任意一路数玩法，模拟 40 局，**中位天数 ≥ 140**，且 **≥30% 的局 day≥200**。  
- 见底结局占比下降到总模拟的 ≤35%（现在容易被四项拖死）。  
- 每条路数专属收场在模拟中 ≥5%。  
- 称帝相关总占比 8%～18%（稀有高光，不是常规）。  
- 同一次运行内 once 工程/办学绝不重复。

### 9.3 文风

继续轻松讽刺。病死是「青楼的灯还亮着」；兵败是「回到县里的尺寸」；开城是「堂下不知道跪哪边」。不写血腥，不写说教。

## 10. 内容体量总目标（终极形态数字）

| 资产 | 现在约数 | 终极目标 | 备注 |
|---|---|---|---|
| 角色 | 12 | 18～20 | 加：盐商、漕丁、邻县令、郡主使者、门子、按察私访等 |
| 卡牌 | ~100+ | 280～320 | 其中 once/链 ≥55% |
| 朝报 | ~78 | 120～140 | 继续无选择；按县面/国势加权 |
| 结局 | ~20 | ~40 | 见第 9 节 |
| 成就 | 8 | 24～30 | 解锁卡包 |
| 路数定性事件 | 苗头 | 5 条主链 × 2～3 变奏 | 支柱一 |
| 人物弧 | 散 | 12～16 条满弧 | 支柱二 |
| 县面标签 | 无 | 6 | 支柱三 |

**关键认知：** 320 张不是让玩家一局看完；一局仍看 40～80 张。多出来的是「另一条命会看见的世界」。

## 11. 可玩性工程（文字游戏的手艺）

### 11.1 防重复三定律

1. **once 定律**：工程、办学、定性、弧拍、称帝相关，一局一次。  
2. **主题冷却**：同一 `theme`（税、婚、匪、河）18～24 抽内不连发。  
3. **朝报只听一次**：现有 `heard` 继续；听完宁可不报，也不复读。

### 11.2 信息密度

- 卡文本 ≤90 字，选项 ≤9 字，余韵 ≤18 字——保持。  
- 提高可玩性靠 **分叉后果**，靠堆长文。  
- 每条中盘链至少 2 拍，让「决定」有时间发酵。

### 11.3 「看得见的变化」

沿用并推广现有 notice：

- 升官、称帝、换国号、跳级、调任、定性事件触发，都必须当帧红字。  
- 朝报不抢更强 notice。  
- 路数首次≥3、≥6 时，可用一句极短 notice（「城里开始传你贪」），每档一次。

### 11.4 教程与规矩

规矩页只描述体验：

- 你常做的事，会引来同一类人。  
- 县有各自的麻烦。  
- 熟人会记着你。  
- 上一任留下的东西，下一任还能看见。

不写：计数阈值、抽牌顺序、权重公式、队列优先级。

## 13. 分期落地（同一方案切四刀，不是四个方案）

> 每一期结束，游戏都必须可玩、可测、可上传。数字是目标，不是并行宇宙。

### 第一期 · 路数骨骼（优先）

- 五路数计数 + 抽牌加权 + 5 条定性大事件主链。  
- 补齐每条路至少 2 个收场（含现有病榻/调任/开城/混过的扩写）。  
- 规矩页一句话点明「常做的事会引来同一类人」。  
- 验收：路数模拟达标（见 9.2）。

### 第二期 · 人物弧十二满贯

- 12 名原班人马每人 4 拍弧 + bond。  
- 弧与路数互相喂牌（贪墨弧推进 graft 等）。  
- 验收：1000 局随机，弧终点触发率与分布健康；无断链。

### 第三期 · 县域与局内改任

- 6 县面 + 朝报加权 + 局内改任一次。  
- 边县叛国、盐县、水县内容包。  
- 验收：不同县面 40 局卡面重叠率显著低于同质局。

### 第四期 · 史册回声与成就卡包

- world echo、成就扩到 24+、解锁包、新角色 6～8 人。  
- 卡总量冲到 280+，结局 ~40。  
- 验收：第 5 任起，回声卡出现率 ≥25% 的局；留存向的「再来一任」理由充足。

广告：全程只增强「自愿看」的烧香/偶发插屏；不解锁数值碾压。

## 15. 最终验收清单（终极形态什么叫「够了」）

当且仅当下列全部成立，才称本方案落地完成：

1. 玩家能清楚说出：「我这一任是贪官局 / 清官局 / 享乐局…」且牌面确实不同。  
2. 任意生活方式都能玩到中途并有体面收场；见底劝退占比可控。  
3. 至少 12 个角色让人产生「我欠他的 / 他欠我的」。  
4. 边县、盐县、水县等打开，体感不是换皮文案。  
5. 第 5 任能看见第 1～4 任留下的世界痕迹。  
6. 升到一路与称帝后，内容不空，也不变成第二种游戏。  
7. `npm test` 全绿；1000 局必结束；结局与路数分布在目标带内。  
8. 规矩页仍是玩法说明，没有引擎说明书气味。  
9. 变现仍是纯广告；无内购。  
10. 文风仍是轻松讽刺的县衙世态。

## 16. 给后来执行者的一句钉

**少加「又一件案子」，多加「让案子属于某一条命」。**

先立路数，再铺人物弧，再给县一张脸，再让历任说话。  
按这个顺序砍，文字官场的可玩性会线性上涨；反过来先堆案情，三个月后仍会觉得「有点雏形，不够」。

规矩页仍是玩法说明：常做的事会引来同一类人，县有各自的麻烦，上一任的桥、学、恩怨下一任还能遇见。交情到了的人，下一任更早来找你。同一类的事连着传来，这县也会沾上。变现仍是纯广告。

**这一轮补上的**

1. **主题冷却。** 税、婚、匪、河、盐、考，正文对得上就标上。同一主题 18 抽之内有别的牌就先抽别的。退堂再回来，这笔记在这一任上。
2. **十二人第四拍。** 王婆到狐仙各接了一张收束。师爷在割席之前多了两拍。钦差从问桥到留评语，四拍。
3. **朝报 120 条。** 补到方案下限。
4. **路数跟着选项走。** 选项里写了清正、贪墨、乐逸、武备、权谋的牌，抽牌时算进那一路。现有 164 张。

**接着补上的**

- 写明县面的牌，在本县的抽牌权重是普通牌的 2.4 倍。穷县加了逃户要地，水县加了夜里敲锣，学县加了书院刻名，乱县加了夜敲门。日常牌各县仍能抽到。
- 盐商、邻县令、漕丁、按察各补到至少四张。使者从借道、再留一夜，到过境名单。
- 贪墨、乐逸、武备、权谋到 8，并且日子够了，才另开一场可拒的收场。不到 8 抽不到。清名晚期仍是 9。
- 朝报按县面加重：盐县更常听见盐，水县听见河，边县听见边关，学县听见科举，穷县听见米价和蝗，乱县听见匪。别的朝报仍会来。
- 升到知府以后，没写官级门槛的村口牌权重降到 0.45；写了门槛、而且你已经够到的一路牌升到 1.8 倍。村口的事还在，只是不再占满升上去的日子。
- 登基后先过三张政务：年号、宗室要爵、开不开恩科。仗仍排在后面，这一任不在这三张上收场。一局仍只称帝一次。
- 跨任记下此人最高交情，以及弧的第四拍见过没有。交情到过 2，或弧已收束，下一任这条弧最早第 12 天就能开，抽到的机会也更勤。交情回落不会把最高那一档抹掉。
- 朝报可以给本县再沾一个县面。匪讯、开科、决口、过境、米价、盐政，同一类听到第二回才加。已经有两面就不再加。匪散了、河没决、米价回落不算。调去别的县，这笔记清掉。升官那一行还在时，不盖掉。
- 抽牌次序按第 7.4 节：已经排上的故事先来，吏部升官先于年终考核，年终考核先于交印、称帝、兵和圣旨，最后才是日常。年终考核到了，不再被当兵那张吃掉；故事还排着，年终考核也不提前。
